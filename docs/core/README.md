# Coordenação do AIOS

O [AIOS](AIOS.md) define o plano, seleciona recursos, coordena a execução e valida o resultado.

A execução pode usar protocolos, skills, personas e ferramentas em conjunto ou separadamente. As verificações podem exigir nova investigação; o fluxo não é uma sequência obrigatória e única.

Consulte o [mapa do sistema](../aios-persona-map.md), a [arquitetura](../architecture/layers.md), a [Constituição](../constitution/aios-constitution.md) e o [DOCOPS](../../DOCOPS.md).
