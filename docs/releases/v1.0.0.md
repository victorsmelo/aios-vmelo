# AIOS v1.0.0

**Data do marco documental:** 2025-12-20  
**Estado:** Marco histórico documental

## Escopo

Marco inaugural do AIOS. Estabelece a fundação institucional do sistema: constituição, protocolo cognitivo, personas base e documentação operacional.

## O que foi entregue

### Adicionado

- Constituição formal do AIOS (governança e separação de poderes)
- Protocolo cognitivo **FOCUS** (Find, Organize, Condense, Understand, Synthesize)
- Persona **F0NT** (Estratégia — Disciplina e Liderança)
- README conceitual do AIOS
- Manifesto do AIOS
- DOCOPS — processo de documentação e governança evolutiva
- Processo oficial de versões do AIOS
- Índice e mapa de personas
- Lista de verificação de cobertura documental

### Alterado

- Reorganização e simplificação dos grupos de personas
- Normalização de caminhos com caracteres ASCII para compatibilidade com GitHub
- Consolidação da distinção entre protocolo cognitivo e persona

## Notas

Este marco estabelece a base institucional do AIOS. Evoluções futuras devem preservar a separação entre método, domínio e decisão.
