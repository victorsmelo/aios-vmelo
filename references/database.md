# Database de Referências (Campos)

- **id**: identificador único curto (ex.: `ref-2025-01`)
- **title**: título da obra/link
- **author**: autores (separados por `;`)
- **year**: ano de publicação (se souber)
- **type**: tipo (book, paper, article, post, video...)
- **link**: URL
- **topic**: tópico principal (ex.: design-ops, tokens, acessibilidade)
- **tags**: tags livres (separadas por `;`)
- **quality**: 1–5 (nível de qualidade/autoridade)
- **notes**: observações curtas sobre o conteúdo
- **where_to_use**: em quais personas/prompts isso ajuda (ex.: DSYS;A11Y)
